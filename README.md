## Overview

### Motivation

- ITonlinelearning course project

I wanted to build an application encompassing all the elements that I learnt in the JavaScript course.


- Conditional statements
- A switch statement
- If / else statements
- Create elements to display in the DOM
- Use a for loop
- Use the toggle() method to add and remove a classList


### Learning Outcomes

- Learnt that when the user inputs a number in HTML it is a string and needs to be converted to a number to enable calculations.
- Learnt how to use setTimeout() to add and remove CSS classes, this enabled effects to the buttons when clicked on.
- Learnt how to use the console for debugging
- Learnt about the typeof operator

## Project Features

- Functionality to carry out calculations
- A display to show all the calculations in a particular sum
- Functionality to change the colour theme
- Functionality to change the font style
- Functionality to display the date and time
- Implemented CSS to add button and hover effects.

## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/calculator-js.git
cd calculator-js
```

### Install Dependencies

Frontend:

```bash
npm install
```

### Run Application

Frontend:

```bash
npm start
```
